# Task Template

## Goal

Describe the smallest useful documentation capability to add.

## Inputs

- Source files or generated artifacts.
- Expected contract output.
- Required references or ecosystem documents.

## Acceptance

- Fixture added or updated.
- Release gate passes.
- Public API comments are bilingual.
- Dependency license impact is recorded.

## Notes

Record whether the change belongs to XML doc intake, Roslyn semantic extraction,
DocFX bridge, ASP.NET endpoint intake, source-linkage, or producer integration.
